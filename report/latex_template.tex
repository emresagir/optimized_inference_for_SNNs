\subsection{Spiking Neural Networks}

Spiking Neural Networks (SNNs) are a class of artificial intelligence. Aiming to mimic how a brain works.
They process information in discrete-time with spikes. These spikes are essentially ones and zeros for a neuron's output.
This makes them great for edge devices with energy and performance constraints.

There are different neuron models; some are focused on biophysical accuracy, and some are focused on simplicity.
The Leaky Integrate-and-Fire (LIF) models are, in a sense, in the middle.

\subsubsection{Leaky Integrate And Fire Model}

In the LIF neuron model, every neuron has an individual membrane potential that decays over time.
Every time a neuron's membrane potential passes the specified threshold, a spike occurs, and its membrane potential is reset with a mechanism.

There are two mechanisms: reset-by-subtract (soft reset) and reset-to-zero (hard reset).
The soft-reset mechanism works by subtracting the threshold when a spike occurs; on the other hand, with a hard-reset, it resets to zero.

The LIF model's membrane potential equation is given in Equation~\ref{eq:lif_eq}. This equation is being used to calculate the membrane potential of the next timestep.
The membrane potential decays at every timestep with a specific decay rate; then, the accumulated input is summed, and lastly the soft-reset is applied. 
\begin{equation}
    U[t+1] = \underbrace{\beta U[t]}_{\text{decay}} + \underbrace{W X[t+1]}_{\text{input}} - \underbrace{S[t] U_{\text{thr}}}_{\text{reset}}
    \label{eq:lif_eq}
\end{equation}

\begin{tabular}{r l}
  $U[t]$ & Membrane potential at time step $t$. \\[0.5em]
  $\beta$ & Membrane decay factor. \\[0.5em]
  $W$ & Learnable parameter (weight). \\[0.5em]
  $X[t+1]$ & Input voltage of the next time step. \\[0.5em]
  $S[t]$ & Spike indicator. \\[0.5em]
  $U_{\text{thr}}$ & Thershold potential. 
\end{tabular}
\\

\subsubsection{Reset Mechanisms}

The reset mechanisms are reset-by-subtract (soft reset) and reset-to-zero (hard reset), as stated before.

Soft reset is when a spike occurs; it subtracts the threshold, which allows the residual potential to remain, providing more accuracy.
With a hard reset, the accuracy might drop, but it might be cheaper to reset a register to zero~\cite{eshraghian2023training}.

\subsubsection{Convolution}
The convolution operation in neural networks occurs when a learnable kernel shifts over an input tensor.
The 2-dimensional convolutional neural network has an input tensor of rank 2, with neurons represented in a 2-D array.
They are connected to the feature map (output matrix) with learnable kernels.
This introduces weight sharing, which reduces the memory load.

An example input feature map, kernel, and the output feature map are given in Figure~\ref{fig:example_conv_layer}.
Every element of the input and output matrices represents a neuron (or activation). The convolution operation's steps are shown in Figure~\ref{fig:conv_Steps}.
The kernel's every element is multiplied by the corresponding element of the input matrix, and then they are summed up.
Lastly, this value is saved to the corresponding position of the output neuron.
This process is repeated until the input matrix is traversed.  

It is understandable that the output matrix's size depends on the kernel, stride and padding parameters.
The stride parameter decides how much kernel moves to the next position, if stride increases the output matrix dimension will be smaller.
The padding parameter is also configurable, vary in size and values. 
It works with adding specific values to the borders to prevent the loss of border feature information.
And both parameters control the dimensions of the output matrix.~\cite{li2022survey}.

However, snn2mcu lacks the support for soft-reset mechanism and convolution connectivity.

Several works targets the efficiency with weight sparsity and pruning. 
Lightweight Software Kernels and Hardware Extensions for Efficient Sparse Deep Neural Networks on Microcontrollers~\cite{daghero2025lightweight},
uses N:M structured sparsity to store the weights, the indices of the weights are stored to be used in execution.
They introduce decimated im2col buffer to be used with the weight indices to calculate the inference.
This approach reduces the memory access count with the cost of not using optimized CMSIS-DSP library. 
Thus the trade-off point depends on the sparsity ratio.
Another work, Compression and Inference of Spiking Neural Networks on Resource-Constrained Hardware~\cite{jurzec2025compression},
built a toolchain which prunes the near-zero weights, compresses the model and generates C representations. 
\\


On the other hand some works focuses on activation sparisty and execution optimization.
Efficient CNN Inference on Ultra-Low-Power MCUs via Saturation-Aware Convolution~\cite{li2026efficient},
skips the multiply and accumulate (MAC) operations for the already saturated neurons. 
\\


To achieve activation sparsity in convolutional networks, the effected output neuron needs to be known. 
There are couple of approaches, storing a pre-computed rulebook or calculating the address on the go, are among those.

Submanifold Sparse Convolutional Networks~\cite{graham2017submanifold}, 
constructs a rule-book with the active (non ground-state) neurons and its effective output neuron pairs, then this is used in GEMM operation. 
Moreover, the rule-book has only the output neurons which is their receptive field's center is active.
Consequently, the features cannot dilate or spread, which results in a slight increase of the error rates.

Spike-based dynamic computing with asynchronous sensing-computing neuromorphic chip~\cite{yao2024spike},
uses a function to find the affected output to achieve asynchronous, event-driven convolution.
When a spike occurs, its address mapping function outputs the affected address on the output map.
Then, the kernel is placed at that input point as an anchor, and the convolution is calculated.
This eliminates unnecessary calculations and memory, with the cost of overhead resulting from the address mapping.



One of the earliest examples of event-driven SNNs is Event-Driven Simulation of Networks of Spiking Neurons~\cite{watts1993neurips-eventdriven},
instead of evaluating every neuron at every timestep, computation is performed only when a spike (an event) occurs.
This mechanism works dynamically; every event and affected consecutive neuron is queued.

\subsection{Soft Reset}
The first thing to implement is Soft Reset (Reset-by-subtraction), 
The previous work had only the hard reset (Reset-to-value) and lacked the soft reset mechanism.

The soft-reset mechanism introduced here follows the same approach as in Eshraghian et al. \cite{eshraghian2023snntorch}.
Also, it is implemented in the \texttt{snnTorch} Python library in the same way, enabling the Python golden reference to match this work. 
The mathematical representation of the soft-reset mechanism is given in the last part of Equation~\ref{eq:soft_reset}.

\begin{equation}\label{eq:soft_reset}
U[t] = \underbrace{\beta U[t - 1]}_{\text{decay}} + \underbrace{W X[t]}_{\text{input}} - \underbrace{S_{\text{out}}[t - 1]\theta}_{\text{reset}}
\end{equation}


In Figure~\ref{fig:soft-reset-c}, the soft-reset implementation in C is given.
First, the current timestep membrane update is being calculated with vectorized ARM functions. 
After the membrane update, the spike check is done. 
While comparing the potential to the threshold, if there is a spike, 
the threshold value is saved to be subtracted at the next timestep. 

\begin{figure}[h]
\centering
\begin{lstlisting}

    // Membrane Update
    q15_t temp1[num_neurons], temp2[num_neurons];

    arm_mult_q15(membrane_potentials, decay_factors, temp1, num_neurons);
    arm_add_q15(temp1, weighted_inputs, temp2, num_neurons);
    arm_sub_q15(temp2, reset_values, membrane_potentials, num_neurons);

    // Spike check, then store reset_value for the NEXT step
    for (uint16_t i = 0; i < num_neurons; i++) {
        if (membrane_potentials[i] > thresholds[i]) {
            output_spikes[i] = 1;
            neurons[i].reset_value = thresholds[i];   // subtract next step
        } else {
            output_spikes[i] = 0;
            neurons[i].reset_value = 0;
        }
        neurons[i].membrane_potential = membrane_potentials[i];
    }

\end{lstlisting}
\caption{Soft-Reset Implementation in C}
\label{fig:soft-reset-c}
\end{figure}





\subsection{Convolutional Support}

The basic convolutional support's pseudo-code shown in the Figure~\ref{fig:basic_conv}.

The convolution calculation is done with a sliding window in a deductive manner, from the output neuron to the input neuron.
For every output neuron an accumulator variable is set, 
then the where sliding window is pointing in the input feature map is calculated. 
With these coordinates the activation value and the weight is multiplied and added to the accumulation.
%TODO: Change the multiply part if this is changed.
This loop is repeated for all the output feature map. 

\begin{figure}[h]
\centering
\begin{lstlisting}

for each output channel o:
  for each output row h:
    for each output column w:
      accumulator = 0

      for each input channel i:
        for each kernel row fy:
          for each kernel column fx:
            
            ih = h * stride + fy - padding 
            iw = w * stride + fx - padding

            if ih and iw in the bounds:
              accumulator = accumulator + input[i,ih,iw] * weight [o,i,fy,fx]

      output[o,h,w] = accumulator

\end{lstlisting}

\label{fig:basic_conv}
